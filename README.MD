🌡️ Temperature Analysis Program

This Python program takes temperature input from the user for 7 days, analyzes the data, and provides a complete weather report.


📌 Features

✔ Takes temperature input for 7 days
✔ Calculates highest, lowest, and average temperature
✔ Categorizes each temperature as Hot, Normal, or Cold
✔ Sorts all temperatures
✔ Shows weather trend (Warmer / Colder / Same)
✔ Clean and beginner-friendly Python code

🚀 How It Works

The program runs in four major steps:

1️⃣ Input

User enters temperature for each of the 7 days.

2️⃣ Functions Used

get_stats()
Calculates highest, lowest, and average temperature.

categorize_temp()
Categorizes each temperature as:

Hot (>= 33°C)

Normal (>= 28°C)

Cold (< 28°C)


weather_trend()
Compares day-to-day temperatures to show trend.


3️⃣ Processing

The program:

Finds highest, lowest, average

Categorizes each temperature

Sorts the list

Checks weather trend


4️⃣ Output

Displays:

Temperatures entered

Highest, lowest, average

Category of each day

Sorted temperatures

Weather trend
